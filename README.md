# Hitjam Radio App

**Hitjam Radio** is a lightweight, ad-free Progressive Web App (PWA) designed primarily for car entertainment and mobile devices. It is built using **Vue 3** and **Vite**, and belongs to the **Hitjamparty** group ecosystem.

## 🚀 Key Features

* **Official Link:** Available online at [radio.hitjamparty.com](https://radio.hitjamparty.com).
* **Progressive Web App (PWA):** Installs directly onto your mobile phone or car dashboard interface without an app store.
* **Integrated Service Worker:** Features background automatic updates (Auto Update), ensuring you always use the latest version.
* **100% Ad-Free:** Enjoy uninterrupted music with zero advertisements.
* **Completely Free:** Open and free to use for everyone.

## 📱 How to Install (PWA)

1. Open [radio.hitjamparty.com](https://radio.hitjamparty.com) in your mobile or car browser (Chrome/Safari recommended).
2. Tap the browser **Menu** button (usually represented by **three vertical dots `...`**).
3. Select **Install** or **Add to Home Screen**.
4. Confirm the installation. The app icon will appear on your screen like a native application.

## 🛠️ Project Setup & Development

If you want to run the project locally or contribute to the development, make sure you have [Node.js](https://nodejs.org/) installed, then use the following commands:

```bash
# Install project dependencies
npm install

# Compile and Hot-Reload for Development
npm run dev

# Compile and Minify for Production Build
npm run build
```

# Hitjam Radio App

**Hitjam Radio** is een lichtgewicht, advertentievrije Progressive Web App (PWA) die primair is ontworpen voor entertainmentsystemen in de auto en mobiele apparaten. De applicatie is gebouwd met **Vue 3** en **Vite** en maakt deel uit van het **Hitjamparty** groep-ecosysteem.

## 🚀 Belangrijkste Kenmerken

* **Officiële Link:** Online beschikbaar via [radio.hitjamparty.com](https://radio.hitjamparty.com).
* **Progressive Web App (PWA):** Kan direct op uw mobiele telefoon of het dashboardscherm van uw auto worden geïnstalleerd zonder app store.
* **Geïntegreerde SW Auto Update:** Uitgerust met een ingebouwde service worker die zorgt voor automatische updates op de achtergrond.
* **100% Advertentievrij:** Geniet van ononderbroken muziek zonder enige reclame.
* **Vrij te gebruiken:** Volledig gratis en open voor alle luisteraars.

## 📱 Installatiehandleiding (PWA)

1. Open [radio.hitjamparty.com](https://radio.hitjamparty.com) in de browser van uw telefoon of auto (Chrome/Safari aanbevolen).
2. Tik op de **Menuknop** van de browser (meestal herkenbaar aan de **drie verticale puntjes `...`**).
3. Selecteer **Installeren** of **Toevoegen aan startscherm**.
4. Bevestig de installatie. De app verschijnt nu als snelkoppeling op uw startscherm.
